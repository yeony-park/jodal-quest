Windows x64에서는 README 상단에서 EXE를 내려받아 더블클릭하세요. 기본 브라우저에 게임이 열립니다.
HTML 버전은 dist/index.html을 브라우저로 여세요. dist 폴더의 HTML·CSS·JavaScript·글꼴을 함께 유지하세요.
게임 시작하기로 시작하고 저장 기록이 있으면 이어서 하기를 누릅니다.

조작
방향키 / WASD로 화면 방향에 맞춰 이동합니다. 대상 이름을 누르면 자동으로 걸어갑니다.
휴대전화에서는 방향 버튼을 길게 누르고, 가까운 대상 옆에서 대화 버튼을 누릅니다.
Space는 문장 전체 보기와 다음 대사, E는 가까운 대상과 대화, Q는 퀘스트 노트입니다.
화면의 다음 목표로 이동은 지금 할 일을 안내합니다. 다른 층의 목표는 먼저 엘리베이터로 안내합니다.
용어 수첩에서 설명과 공식 자료 링크를 읽고, 하단 7칸의 물건을 눌러 내용을 확인하세요. 서류 제출 요청이 뜨면 가방의 서류를 서류 놓는 곳에 끌어 놓습니다. 터치나 키보드로는 서류를 고른 뒤 펼치기 또는 건네기를 누릅니다. 다른 물건은 힌트를 받고 감점 없이 다시 고릅니다.

여섯 업무
1. 김주문에게 업무를 듣고 수요기관에 납기를 확인한 뒤 요청서를 보완합니다.
2. 김주문에게 규격 조언을 듣고 성능 기준으로 수정합니다.
3. 업무용 모니터 → 발주 → 로그인 → 수량 2를 20으로 수정 → 검토본 저장.
   모니터를 닫고 김주문에게 검토를 요청하면 담당자 결재 후 공고를 게시합니다.
4. 기업 담당자 욘 대리로 전환합니다. 제품 자료에서 새봄 M24를 고릅니다.
   모니터 → 로그인 → 공고 상세 → 입찰서 작성 → 참가 조건 확인 → 입찰서 제출.
5. 조달달로 돌아와 엘리베이터 → 2층 → 계약 담당자 설명 → 개찰·계약 자료 → 예정가격 확인 → 계약 담당자의 전자계약 체결 → 계약서 수령과 배웅 대화.
6. 엘리베이터 → 5층 → 수요기관 납품 자료 → 부족한 1대 보완 요청 → 다시 납품 자료 확인 → 검사·검수와 인수.
   업무용 모니터에서 영수증·납품 서류 확인 → 대금 지급 → 여섯 업무 복습과 최종 레벨 엔딩.

예정가격은 입찰 전에 결정해 둔 자료를 확인합니다. 입찰서 접수 뒤 심사와 계약 절차가 이어집니다.
기관·인물·기업·물품·금액은 가상 설정이고 심사 세부 내용과 대기 시간은 줄였습니다.
미니맵에서는 층별 지도를 봅니다. 엘리베이터에서 B1~9층 버튼을 누르면 이동합니다. 7층 도서실에서는 문다은에게 용어 카드를 받습니다. 본청의 층별 대표 공간을 참고했으며 2층 계약팀은 게임 전용 공간입니다. 기업 장면은 별도 사무실로 표시하고 배치를 재사용합니다.

잘못된 선택과 업적
잘못 고르면 선배가 이유를 짚어 주고 대신 처리합니다.
엔딩은 수습 0개 정파, 1~2개 정파 · 수습을 배운 신입, 3개 이상 사파입니다. 수습별 업적을 표시하고 진행 중인 수습도 저장합니다. 이전 저장의 오답 횟수도 칭호에 반영합니다.
다음 목표만 깜박이고 동작 줄이기 설정에서는 깜박임을 끕니다.

저장과 소리
같은 브라우저·같은 주소에서 퀘스트 진행과 현재 층을 자동 저장합니다.
예전 네 퀘스트 완료 저장은 새 계약 퀘스트부터 이어집니다. 정확한 캐릭터 위치와 나라장터 로그인은 시작할 때 초기화합니다.
저장이 제한된 환경에서도 현재 창에서 플레이를 계속합니다.
조달달은 사용자의 녹음, 욘 대리는 기존 팀원 녹음의 발성 조각을 사용합니다. 다른 인물은 합성 발성 효과를 사용합니다.
대화마다 조달달의 답변이 이어집니다. 소리 버튼에서 대화 음성·배경음악·효과음을 따로 켜거나 끌 수 있습니다. 배경음악은 0~100으로 음량을 조절합니다. 두 녹음의 기본 재생 속도는 1.4입니다.

로컬 서버 실행
개발 시 Node.js 22 이상에서 npm ci, npm run dev를 실행하고 http://127.0.0.1:8765 에 접속합니다.
배포 폴더를 서버로 제공하려면 저장소 루트에서 다음을 실행합니다.
python3 -m http.server 8765 --bind 127.0.0.1 --directory dist
해당 터미널에서 Ctrl+C로 종료합니다. 파일 직접 실행과 localhost는 저장 공간이 다를 수 있습니다.
