조달의 달인 · 도트 2.5D 쿼터뷰 개정판
갱신: 2026-11-21

시작
저장소를 내려받아 루트의 index.html을 브라우저로 여세요.
게임, 도트 그래픽, 한국어 손글씨체, 여성 기업 담당자의 실제 녹음이 HTML 하나에 들어 있습니다.
설치나 로그인 없이 실행되며 게임 내부의 나라장터는 모의 화면입니다.
게임 시작하기 → 김주문 튜토리얼. 저장 기록이 있으면 이어서 하기.

화면과 조작
- 화면 전체를 채우는 도트 2.5D 쿼터뷰 사무실.
- 좌측 상단 미니맵: 초록은 나, 노랑은 다음 목표.
- 우측 상단 퀘스트 또는 Q: 김주문이 손으로 적어 준 미색 줄노트.
- 하단 인벤토리: 정확히 5칸. 사원증 → 요청서 → 규격서 → 공고문 → 접수증.
- 획득한 물건을 누르면 내용을 다시 확인합니다.
- 방향키 / WASD: 화면 방향으로 이동. 벽과 가구를 통과할 수 없습니다.
- 대상 이름을 누르면 복도를 따라 자동으로 걸어가 상호작용합니다.
- 가까운 대상에서 Space / E: 상호작용.
- 대화 중 Space: 문장 전체 표시, 다시 Space: 다음 말로 진행.
- 화면의 Space 버튼도 사용 가능합니다. 문서 선택지는 클릭·터치 또는 Tab과 Enter.
- 노트의 다음 목표로 이동 버튼으로 각 퀘스트를 진행하면 됩니다.

나라장터 체험
업무용 모니터를 사용하는 순간에만 열립니다.
공무원: 모니터 → 체험 로그인 → 공고 초안 수량 2대를 20대로 수정 → 검토본 저장 → 사무실로 돌아가기 → 김주문 검토 → 담당자 결재 후 게시.
기업: 제품 자료에서 새봄 M24 선택 → 모니터 → 입찰 또는 공고 검색 → 게시된 공고 상세 → 체험 로그인 → 공고 상세 → 입찰서 작성 → 참가 조건 확인 → 모의 제출.
로그인을 먼저 하면 공고 상세를 다시 여는 과정을 줄일 수 있습니다.
실제 계정이나 인증서를 요구하지 않고 실제 나라장터에 데이터를 전송하지 않습니다.

캐릭터와 엔딩
조달달: 신입 9급 주무관, 확인과 초안 작성 담당.
김주문: 선배 NPC, 검토와 조언 담당.
한빛 대리: 여성 기업 담당자 NPC. 네 번째 퀘스트에서 잠시 플레이어로 전환.
수요기관 담당자는 전화 대화로 등장합니다.
기업 단계는 별도 기업 사무실이며 간결한 체험을 위해 맵 배치를 재사용합니다.
완료 후 조달달로 돌아와 Lv. 1 → Lv. 2, “이제 나도... 조달의 왕이야!” 엔딩.
“더 많은 퀘스트를 깨고 싶다면?”은 사용자가 지정한 조달청 채용정보 링크입니다.

저장
퀘스트 달성 즉시 localStorage에 진행 상황을 저장합니다.
완료 안내창에서 다음 버튼을 누르기 전 새로고침해도 완료한 퀘스트와 물건이 복원됩니다.
같은 브라우저와 같은 주소에서 이어하기를 사용하세요. 파일 이동이나 브라우저 저장 삭제 시 기록이 달라질 수 있습니다.
저장이 제한되면 안내를 표시하며 현재 창에서는 계속 플레이할 수 있습니다.
사운드는 HTML에 내장했으므로 다시 불러올 필요가 없습니다.

사운드
첨부한 4.48초 M4A 녹음에서 발성을 골라 한빛 대리에게 고정 적용했습니다.
사운드 설정은 음량, 음소거, 한빛 대리 목소리 미리듣기만 제공합니다.
사용 중 팀원 목소리 파일을 불러오는 옵션은 제거했습니다.
김주문·조달달·수요기관 담당자는 기본 합성 웅얼거림을 사용합니다.
게임 시작이나 버튼 클릭 이후 소리가 활성화됩니다. 배경음악 대신 대화 소리와 퀘스트 완료 효과음만 포함했습니다.

로컬 서버 실행 (선택)
저장 주소를 일정하게 유지하려면 저장소 루트(index.html이 있는 폴더)에서 실행합니다.
macOS / Linux: python3 -m http.server 8765 --bind 127.0.0.1
Windows: py -m http.server 8765 --bind 127.0.0.1
브라우저 주소: http://127.0.0.1:8765
종료: 해당 터미널에서 Ctrl+C.
파일 직접 실행과 localhost는 저장 공간이 다를 수 있습니다.
