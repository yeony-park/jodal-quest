# 팀원 인수인계

기준일: 2026-11-21. 현재 커밋은 플레이 가능한 HTML MVP입니다. 디테일 수정은 아래 위치부터 이어가면 됩니다.

## 실행과 편집

저장소 루트의 `index.html`이 실행 파일이자 원본 소스입니다. 직접 수정 후 브라우저를 새로고침합니다.
CSS·HTML·JavaScript가 한 파일에 있고, 글꼴과 음성은 base64로 내장되어 있습니다. 별도의 생성 스크립트를 실행해야 반영되는 구조가 아닙니다.
파일 앞부분의 긴 글꼴 데이터와 `supplierVoiceData` 문자열은 일반 화면·대사 수정 때 건드리지 않아도 됩니다.

단일 파일 실행을 유지하려고 별도 빌드 도구를 넣지 않았습니다. 이전 실험용 생성 스크립트나 임시 모듈을 실행하면 현재 버전을 덮어쓸 수 있으므로 이 저장소에는 넣지 않았습니다.

## 유지할 핵심 흐름

1. 조달달이 수요기관에 빠진 납기를 확인하고 요청서를 보완합니다.
2. 김주문의 조언을 듣고 성능 중심 규격 수정안을 고릅니다.
3. 업무용 모니터에서 공고 수량을 2대 → 20대로 수정하고 검토본만 저장합니다. 선배 검토와 권한 있는 담당자의 결재 후 공고가 게시됩니다.
4. 욘 대리로 전환해 적합한 제품을 고르고, 모니터에서 공고를 찾아 참가 조건을 확인한 후 모의 입찰서를 제출합니다.
5. 조달달로 복귀해 Lv. 2 엔딩. “이제 나도... 조달의 왕이야!”

이 인계 단계에서 범위를 늘릴 필요는 없습니다. 공고를 신입이 독단으로 확정하거나 입찰 접수를 계약 완료로 표현하지 않도록 유지하세요.

## 현재 결정과 제약

- 공무원 플레이어는 조달달, 기업 플레이어는 마지막 단계의 욘 대리입니다. 다른 사람은 NPC 또는 전화 대화입니다.
- 욘 대리만 실제 팀원 녹음을 사용합니다. 김주문·조달달·수요기관 담당자는 합성 웅얼거림입니다.
- 녹음 불러오기 UI는 사용자의 요청으로 제거했습니다. 다른 팀원 음성은 파일을 받은 뒤 코드에 적용하면 됩니다.
- 원본 전체 음성은 포함하지 않았습니다. 실제 발성 조각은 HTML에 내장되어 있고 미리듣기 WAV는 assets에 있습니다.
- 인벤토리는 항상 5칸이며 획득 상태는 퀘스트 진행에서 계산합니다. 별도 아이템 저장 목록이 없습니다.
- `localStorage` 키는 `jodal-master-v1`, 현재 저장 버전은 1입니다. 저장 형식을 바꿀 때 기존 이어하기 영향을 확인하세요.
- 모의 로그인은 개인 계정 입력 없이 버튼 한 번으로 처리하며, 로그인 상태는 새로고침할 때 초기화합니다. 퀘스트는 유지됩니다.
- 기업 사무실은 별도 장소로 표시하지만 간단한 MVP를 위해 같은 맵 배치를 재사용합니다.
- 맵은 조달청 본청 5층 방 배열을 참고한 창작 지방청입니다. 정확한 실제 평면도 재현이 아닙니다.
- 나라장터 첫 화면은 공개 자료를 참고한 축약 화면입니다. 현재 실서비스와 완전히 일치하는 복제 화면은 아닙니다.
- 엔딩의 지정 링크는 조달청 **채용정보** 페이지입니다. 게임 내부 추가 퀘스트로 오해하지 않도록 도착지를 표시했습니다.
- README의 최종 목표에는 EXE가 있으나 현재 제작된 실행물은 HTML뿐입니다.

## 다음 팀원이 먼저 확인할 것

- 실제 Chrome 또는 제출에 사용할 브라우저에서 처음부터 네 퀘스트를 완주하기.
- 로고·노트·대화·나라장터·인벤토리가 겹치지 않는지 실제 화면에서 확인하기.
- 욘 대리 녹음의 음량·웅얼거림과 다른 인물의 합성 소리 차이 직접 듣기.
- 퀘스트 완료 직후 새로고침 → 이어하기로 문서와 다음 단계가 복원되는지 확인하기.
- 소개문 팀명·참가자 정보, 공모전 지정 제출 항목 채우기.

위 항목은 완료했다고 보고하지 않았습니다. 현재 확인된 것은 아래 코드 검사와 Canvas 맵 렌더, 로컬 HTTP 제공입니다.

## 검사 실행과 해석

```sh
node tests/game.test.cjs
```

Node.js 18 이상, 추가 설치 없이 42개 검사입니다. 실제 게임의 인라인 JavaScript를 읽어 모의 DOM·오디오 환경에서 실행합니다.
가구나 출입구를 바꿀 때 목적지 사이 이동 경로 검사를 확인하세요. 기존에는 책상이 문을 막는 문제를 이 검사로 찾아 수정했습니다.
이 검사는 실제 브라우저 렌더링·오디오 디코더·스피커를 대신하지 않습니다. 시각과 소리 변경 후에는 직접 플레이도 필요합니다.
테스트는 현재 내장 음성이 모노 24kHz, 24개의 100ms 구간으로 구성된 2.4초 WAV라는 전제를 포함합니다. 다른 음성 형식으로 교체하면 관련 모의 디코더와 기대값도 맞춰야 합니다.
