갱신 : 2026-11-21

전체 플레이를 먼저 촬영한 뒤 대화와 이동을 줄여 60초로 편집하는 구성입니다.
Space로 문장을 모두 보고 한 번 더 눌러 진행합니다. 화면의 다음 목표로 이동을 사용하세요.

00–06초 | 시작 화면 → 김주문 튜토리얼 → 7칸 가방
멘트 : “신입 주무관 조달달의 첫 구매 업무를 따라가 봅니다.”

06–15초 | 수요기관 연락 → 납기 확인 → 가방의 요청서 제출 → 요청서 보완
멘트 : “빠진 정보는 수요기관에 확인하고 요청서를 채웁니다.”

15–23초 | 김주문 조언 → 가방의 규격서 제출 → 성능 중심 규격 수정
멘트 : “필요한 성능을 분명히 적어 여러 기업이 경쟁할 기회를 열어요.”

23–32초 | 모니터 → 수량 20 수정 → 검토본 저장 → 김주문 검토와 담당자 결재
멘트 : “나라장터 체험에서 초안을 확인하고 검토·결재 뒤 공고합니다.”

32–40초 | 욘 대리 전환 → 제품 선택 → 입찰서 제출
멘트 : “기업의 시선으로 공고와 제품을 확인합니다. 접수 다음에는 심사와 계약이 이어져요.”
기존 녹음 기반 욘 대리의 대화 소리를 잠깐 담습니다.

40–49초 | 엘리베이터 → 2층 계약 체험실 담당자 → 예정가격 자료 → 전자계약과 배웅 대화
멘트 : “입찰 전에 결정한 예정가격과 심사 결과를 확인하고 전자계약 절차를 배워요.”

49–56초 | 5층 귀환 → 19대 부족 확인 → 20대 보완 → 검사·검수 → 대금 지급
멘트 : “수량을 끝까지 확인하고 납품 서류와 대금 지급까지 마무리합니다.”

56–60초 | 정파 또는 사파 칭호 → 수습 업적 → 최종 레벨과 여섯 업무 복습
멘트 : “요청서부터 납품까지, 작은 확인을 쌓아 조달의 달인으로!”

표현과 제작 상태
실제 업무와 다를 수 있다는 안내는 타이틀과 엔딩에 한 번씩 표시합니다.
