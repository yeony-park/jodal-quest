조달의 달인 · 1분 시연 구성

촬영·편집용 60초 시간 배분입니다. 연속 플레이가 정확히 60초라는 뜻은 아닙니다.
전체 과정을 먼저 촬영하고 대화·이동 일부를 줄이면 아래 구성으로 편집할 수 있습니다.
대화는 Space 한 번으로 전체 표시, 다시 Space로 진행합니다.

00–06초 | 로고 → 게임 시작하기
멘트: “신입 주무관 조달달의 첫 출근, 조달의 달인입니다.”

06–14초 | 김주문의 말풍선 → 미색 손글씨 노트 → 쿼터뷰 맵
튜토리얼을 Space로 넘기고 사원증이 들어온 하단 5칸을 보여 줍니다.
멘트: “선배의 조언을 듣고, 업무 노트를 따라 첫 구매를 준비합니다.”

14–25초 | 요청서 접수
노트의 다음 목표 → 수요기관 전화 → 다음 목표 → 요청서.
“확인한 납기를 보완하고 검토를 요청한다” 선택.
요청서가 가방에 들어오는 순간과 자동 저장 표시를 보여 줍니다.
멘트: “빠진 정보는 직접 확인하고, 완료한 업무는 바로 저장합니다.”

25–34초 | 규격 검토
다음 목표 → 김주문 조언 → 다음 목표 → 성능 기준으로 수정안 작성.
멘트: “특정 브랜드보다 필요한 성능을 기준으로 검토합니다.”

34–45초 | 모니터와 나라장터
다음 목표 → 업무용 모니터. 나라장터 첫 화면을 잠시 보여 줍니다.
체험 로그인 → 가상 계정 로그인 → 수량 2를 20으로 변경 → 검토본 저장.
사무실로 돌아가기 → 김주문 검토 → 결재 후 게시 → 기업 담당자로 전환.
멘트: “모니터에서는 나라장터를 체험합니다. 공고는 검토와 결재를 거칩니다.”

45–55초 | 욘 대리의 목소리와 기업 입찰 참여
전환 대화에서 실제 녹음 기반 웅얼거림을 1~2초 들려줍니다.
제품 자료 → 새봄 M24 → 닫기 → 모니터 → 체험 로그인 → 가상 계정 로그인.
입찰공고목록의 새봄도서관 모니터 구매 → 입찰서 작성 → 확인란 체크 → 모의 제출.
멘트: “기업 담당자가 되어 조건에 맞는 제품으로 입찰에 참여합니다.”

55–60초 | 접수증 획득 → 조달달 엔딩 → 레벨업
대화를 넘겨 “이제 나도... 조달의 왕이야!”와 Lv. 2를 보여 줍니다.
마지막 버튼 “더 많은 퀘스트를 깨고 싶다면?”까지 화면에 담습니다.
멘트: “작은 확인들이 만드는 공정한 조달. 첫 번째 퀘스트 완료!”

주의할 표현
입찰서 접수 완료를 낙찰 또는 계약 완료라고 소개하지 않습니다.
엔딩 버튼은 조달청 채용정보로 연결됩니다.
영상 파일 자체는 제작하지 않았습니다.
