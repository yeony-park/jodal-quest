조달의 달인 · 도트 2.5D 개정판 검증 기록
갱신: 2026-11-21

수행한 검증
- JavaScript 문법 검사.
- Node 모의 DOM·오디오 환경에서 43개 검사 통과.
- 실제 Canvas 렌더러로 게임 draw 함수를 실행해 쿼터뷰 맵 이미지를 생성하고 시각 확인.
- 첨부 M4A를 실제 ffmpeg 디코더로 읽어 WAV로 변환. 원본 4.480초 확인.
- 내장 발성 조각 24개의 범위, 실제 음성 데이터, 여성 담당자에게만 배정되는 연결 확인.
- 개발 서버의 HTML·CSS·JavaScript·글꼴 HTTP 응답과 배포 폴더의 모든 자산 연결 확인.
- ZIP 재압축 후 배포 폴더의 파일 일치 확인.

43개 검사의 주요 범위
타이틀과 튜토리얼, Space 문장 표시·넘기기 및 반복 입력 제한.
대화 중 이동 차단, 손글씨 노트와 사원증 획득.
5개 목적지 사이 모든 이동 경로, 벽·가구 충돌, 자동 이동 후 NPC 대화.
요청서와 규격의 오답·정답 및 정보 수집 선행 조건.
각 퀘스트 완료 즉시 저장, 이어하기에서 인벤토리 복원.
모니터 사용 후 나라장터 홈 열기, 모의 로그인, 게시 전 검색 결과 없음.
수량 오류 수정, 초안 저장이 곧 공고가 되지 않는지, 선배 검토·담당자 결재 후 게시.
게시된 공고 검색·상세, 검색 문자열 안전 표시.
기업 로그인, 제품 적합성, 참가 조건 확인 후 제출.
입찰서 접수 후 네 퀘스트·다섯 물건 저장, 조달달 복귀·레벨업·지정 외부 링크.
반복 제출 방지, 완료 기록 복원, 새 게임 초기화.
여성 담당자 음성만 실제 녹음 사용, 다른 역할 합성, 파일 불러오기 UI 제거.
음소거·대화 넘기기 시 음원 중단, 발성 조각 범위와 합성 데이터 범위.
데스크톱·세로·가로 화면의 카메라 계산, 손상되거나 제한된 저장 환경에서 완주.
외부 실행 스크립트·폰트·오디오 네트워크 요청 없음.

검사 중 수정
전화 책상과 모니터 책상이 아래쪽 방 입구를 막는 문제를 이동 경로 검사에서 찾아 수정했습니다.
목적지 사이 25개 조합 모두 접근 가능함을 재확인했습니다.

한계
모의 DOM 검사는 실제 브라우저 CSS 배치나 브라우저 오디오 디코더를 검사한 것이 아닙니다.
Canvas 맵 이미지는 게임 그리기 함수의 실제 결과지만 HUD를 포함한 브라우저 스크린샷은 아닙니다.
현재 앱에서 브라우저 조작 도구가 제공되지 않아 이번 개정판의 실제 브라우저 완주·스피커 청취·기기별 화면 검증은 수행하지 못했습니다.
초기 버전의 실제 Chrome 완주 기록을 이번 개정판의 실기 검증으로 대신하지 않습니다.
이전 JPG 화면 3장은 이번 ZIP에 포함하지 않았습니다.

미수행
실제 브라우저 최종 검수, 공개 배포, 공모전 접수, 시연 영상 녹화.

컴포넌트 분리 후 추가 검증
- 기존 42개 동작 검사를 분리한 JavaScript 모듈에 연결해 재검증.
- 실제 배포 번들의 부팅과 시작 버튼 연결 검사 1개 추가(게임 검사 총 43개).
- HTML/CSS 상대 자산 경로, 글꼴 바이트, 가공 음성 내장, 라이선스 포함 확인.
- 분리 전후 조달달·기업·완료 장면의 실제 Canvas 이미지 바이트 일치 확인.
- 파일과 코드 구성을 바꿨으며 실제 브라우저 완주·청취 미검증 한계는 그대로입니다.
