실제 브라우저
설치된 agent-browser의 headless Chromium을 사용했습니다.
이번 작업에서 시작한 python3 HTTP 서버가 dist를 http://127.0.0.1:8871 에 제공했습니다.
게임 시작하기부터 화면에 있는 버튼·입력란·다음 목표 안내를 조작해 여섯 퀘스트를 끝까지 진행했습니다.
5층에서 시작해 3층 전자계약, 5층 납품·지급으로 돌아왔고 stage 6 저장과 복습 항목 6개를 확인했습니다.
새로고침 뒤 이어하기에서 완료 엔딩을 복원했고 실제 3층 체크포인트를 다시 불러와 현재 층과 다음 목표를 확인했습니다.
1280×720과 390×844에서 두 층의 장면과 엔딩을 캡처하고 확인했습니다.
캐릭터 내부의 배경 격자 틈과 다리 분리 현상은 정지·걷기 화면과 자세 검사에서 해소됐습니다.
390×844에서 방향 버튼을 실제 포인터로 길게 눌러 이동하고, 놓은 뒤 200ms 동안 미니맵 좌표가 고정되는 것을 확인했습니다.
390×844의 가방 측정값은 왼쪽 약 21px, 오른쪽 약 369px, 너비 약 348px로 7칸이 화면 안에 들어왔습니다.
욘 대리 음성은 브라우저 Web Audio에서 모노·44.1kHz·약 2.400초로 디코딩됐습니다.
브라우저 JavaScript 오류 목록은 비어 있었습니다.

실행 중 조정
npm ci는 esbuild 설치 후 실행 검사에서 EPERM으로 실패했습니다. npm ci --ignore-scripts로 lockfile의 두 패키지를 설치했고 실제 빌드와 모든 검사가 통과했습니다.
로컬 서버·브라우저의 기본 샌드박스 소켓 권한이 제한되어 실행 도구의 승인된 권한 경로로 localhost 검증을 진행했습니다.
긴 브라우저 자동 조작 한 번에서 CDP Runtime.evaluate 응답 시간이 초과됐습니다. 실제 저장과 화면 로그로 3층 도착·설명 완료를 확인하고 짧은 구간으로 나눠 엔딩까지 진행했습니다.
브라우저 화면에서 NPC 도착 위치 겹침과 바닥 목표 표시의 몸통 덮임을 찾아 수정하고 자동 검사를 다시 통과했습니다.

공개 배포·공모전 접수·시연 영상 제작은 남아 있습니다.

추가 녹음 적용 검증
사용자 제공 발성 뱅크를 assets/audio/jodal-voice-bank.wav로 복사하고 원본과 SHA-256 일치를 확인했습니다.
조달달과 욘 대리의 뱅크를 각각 내장하고 원본 M4A 제외, 역할별 재생, 녹음 실패 시 대체 소리를 검사해 게임 검사 63개를 통과했습니다.
실제 Chromium에서는 두 뱅크가 각각 모노·44.1kHz·약 2.400초로 디코딩됐습니다.
조달달이 “요청서의 빈칸부터 계약, 납품과 대금 지급까지 마쳤어.”로 시작하는 대사를 말할 때 사용자 뱅크의 버퍼를 재생한 것을 확인했습니다.
버퍼는 입력 WAV의 SHA-256으로 구분했고 발성 구간 길이는 0.085초였습니다. JavaScript 오류 목록은 비어 있었습니다.
소리는 브라우저의 실제 클릭으로 활성화했습니다. JavaScript의 click 호출만 사용한 첫 시도는 재생 확인 대기 시간이 초과돼 실제 클릭 후 다시 확인했습니다.
1280×720의 목표 패널을 위로 옮기고, 390×844에서는 계약 담당자 이름이 조달달 머리·퀘스트 표시와 겹치지 않도록 배치했습니다.
모바일 정지·걷기 위치에서 이름표와 머리·퀘스트 표시의 사각형이 겹치지 않는 것을 측정했습니다.
추가 결과와 화면은 /tmp/jodal-run/followup1-* 파일에 있습니다.
